FAQ

Questions, answered.

Managed AI gives you a private LLM with n8n workflows. An agent of your own goes further: an orchestrator that delegates to specialized sub-agents, with a skills library, memory and scheduled automations. It's the difference between a tool and an employee.

Two layers. Frontier work, the hardest coding and reasoning, runs on Claude Opus 5 and Fable 5/5.1 through a first-party Claude Code subscription. Everything else (conversations, sub-agents, the cron fleet) runs on Ollama Cloud models, pinned per job. You get frontier capability where it counts and flat-rate economics everywhere else: no per-token metering on either layer.

Telegram (your AI talks to you via text/voice), Gmail (read, draft), Instagram (comment alerts and drafted posts you approve), Postiz (multi-platform social scheduling), n8n (workflow automation), and Notion CRM (pipeline tracking). Custom integrations available on request.

A library of skills and scheduled jobs, picked for your workflow. Each skill is a reusable workflow: code review, TDD, debugging, content drafting, SEO audits, security scans, deployment, and more. New skills are added continuously.

You own it. It runs on your VPS, on the open-source Hermes agent. Your files and memory stay on your server; prompts go to the model providers you pick (Ollama Cloud, Claude), which have their own usage limits. You control the models, the tools, and the memory.

Every conversation, decision, and fact is stored in a local semantic memory system (MemPalace). Your agent remembers past sessions, can search its own memory by meaning, and maintains a knowledge graph of people, projects, and relationships. It gets smarter the more you use it.

It depends on how much you want it doing on day one. A single agent aimed at one job is quick; a full stack across several is not. I scope it with you before either of us commits.
