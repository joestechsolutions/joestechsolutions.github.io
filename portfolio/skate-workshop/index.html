The challenge

Build a one-on-one coaching app for a coach of Olympians. Athletes needed a fast way to send trick clips; the coach needed to mark them up with drawings and voice notes, assign homework, and track each athlete's progress across a large trick grid.

The app came first, as an iPhone build in TestFlight, with a pre-launch website and waitlist alongside it.

The solution

Built the app in React Native with Expo on Supabase, with a separate Next.js marketing site and waitlist.

React Native (Expo) app, shipped to TestFlight
Timestamped drawings and synced voice notes on clips
A review queue and homework for each athlete
A 4,952-combination trick grid (140 tricks across stances and obstacles)
Messaging, roster and a progress heatmap
iOS push notifications
Over-the-air updates for code-only fixes
