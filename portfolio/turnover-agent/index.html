Turnover AgentTurnover Agent

An agent that turns every checkout into a cleaning job and keeps it moving until it's done.
Back to portfolio
What it does
  • Watches the booking calendar for each linked property and turns checkouts into cleaning jobs
  • Offers each job to the property's first-choice cleaner on Telegram. If nobody accepts in time, the backup gets it, then the manager
  • Cleaners reply in chat. “Done” marks the job complete, and problems go to the manager
  • Optional per property: photos, a room checklist, and a lock-code check
  • An invite-only web dashboard shows today's turnovers
Runs on

FastAPI, python-telegram-bot, Supabase, and a scheduler on a small VPS

Status

Livesince late July 2026

The problem. Every guest checkout starts a scramble: is the place clean before the next check-in? The manager was texting cleaners by hand, tracking replies by memory, and finding out about a missed clean when the guest was already at the door.

The build. An agent that watches the booking calendar for checkouts, then runs the loop by itself: it offers the job to the first-choice cleaner, reads the cleaner's tap or one-word reply, updates the state, and hands the job to the backup, then the manager, if nobody accepts in time. The manager sees everything in Telegram and on a live dashboard.

Why it's built this way. Nothing new to learn. The manager talks to a Telegram bot; cleaners tap a button or reply with one word. The agent does the chasing and the remembering.

What it's built to do without being asked

Watches the calendar

Polls the booking feed every 15 minutes. A new checkout becomes a turnover automatically: no copy-pasting between apps.

Chases, politely

No confirmation? The backup gets the offer. Still nothing? The escalation watcher flags it to the manager with a plain-English summary of what's stuck.

One-tap replies

Cleaners tap a button or reply with a word (“1”, “done”, “issue”), and the agent moves the turnover to the right state. The LLM sits on the manager's side, answering questions in plain English.

Guest concierge

Built, not yet turned on: a concierge mode for guests who message the bot, with check-out times, local FAQs, and a handoff to the host when it's something real.

The manager's side

A live dashboard next to the agent: today's turnovers with cleaner status at a glance, properties with their calendar and crew.
